Instructions for bulk upload
===================================================================

Start from the sample file and only change the values, not the columns.

  * Easiest route: set the six settings on the upload page, then press "Download template with
    these settings". You get a file with those columns already filled in on every row and the
    rest blank, so all you type is the product's own details.
  * The file has 27 product columns (A to AA) followed by a block of 5 variant columns (AB to AF).
    So a file is 32 columns wide for one variant, 37 for two, 42 for three, and so on.
  * Do not add or remove columns. Every column is read by its position, so one extra or missing
    column shifts everything after it. The upload is refused if the count does not fit.
  * Comma, semicolon and tab separated files are all accepted.
  * Leave any optional column blank if it does not apply. Blank is always safe.
  * The whole file is checked before anything is saved. If one row is wrong, nothing is
    imported and the row number is reported.

-------------------------------------------------------------------
Settings you never have to decode
-------------------------------------------------------------------
Columns U to AA used to be number codes. They are written in plain words now, and the template
you download from the upload page arrives with them already filled in from the choices you made
there. You only touch them if you want one product to differ from the rest.

If you leave one of those cells blank, the setting chosen on the upload page is used instead.

Two more are worked out for you and are never asked for:

  * Stock tracking level - filling the product stock column tracks stock for the product;
    filling the variant stock columns tracks it per variant; leaving both blank means stock is
    not tracked at all.
  * Availability - a product is available unless you set its stock to 0.

Column A is seller_id: the numeric user id of the seller the products belong to, from
Sellers > Manage Sellers. It is not a store name or a code like SELLER001.

-------------------------------------------------------------------
Product columns
-------------------------------------------------------------------

A.  seller_id - mandatory. The numeric user id of the seller these products belong to. Find it
      on Sellers > Manage Sellers. Not a store name, and not a code like SELLER001.

B.  category_id - mandatory. The Category ID shown on the Categories page.

C.  product_type - mandatory. Exactly simple_product or variable_product.
      simple_product   - one price, no options. Fill one variant block.
      variable_product - has options such as size or colour. Fill one variant block per option
                         and give attribute_value_ids on each.

D.  name - mandatory. The product name.

E.  short_description - optional. One line shown next to the product.

F.  description - optional. The full description.

G.  image - mandatory. The main image. Copy the path from the Media page,
      for example uploads/media/2021/07.jpg

H.  other_images - optional. More image paths, separated with commas.

I.  tags - optional. Search words, separated with commas.

J.  sku - optional. Your own code for the product.

K.  stock - optional. How many you have. Fill this when you keep one stock figure for the whole
      product. Leave it blank and use the variant stock column instead when each option has its
      own stock. Leave both blank if you do not track stock.

L.  tax - optional. The tax ID from Products > Tax.

M.  made_in - optional. For example India.

N.  warranty_period - optional. Free text, for example 6 months.

O.  guarantee_period - optional. Free text, for example 1 year.

P.  video_type - optional. Exactly youtube or vimeo, or blank.

Q.  video - optional. The video link.

R.  minimum_order_quantity - optional. The fewest a customer can buy. Blank means 1.

S.  quantity_step_size - optional. Customers buy in multiples of this. Blank means 1.

T.  total_allowed_quantity - optional. The most one customer may buy. Blank means no limit.

U.  cod_allowed - Yes or No. Whether customers can pay cash on delivery.

V.  prices_include_tax - Yes or No. Whether the prices you typed already include tax.

W.  returnable - Yes or No.

X.  cancellable_until - No, Until received, Until processed, or Until shipped.

Y.  food_type - Not a food product, Vegetarian, or Non-vegetarian.

Z.  delivery_area - Everywhere, Only these pincodes, Except these pincodes, or
      Not deliverable yet.

AA. pincodes - only needed when delivery_area is "Only these pincodes" or "Except these
      pincodes". Separate them with commas or spaces.

-------------------------------------------------------------------
Variant columns - repeat these 5 for every extra variant
-------------------------------------------------------------------

AB. attribute_value_ids - required for variable_product, leave blank for simple_product. The
      IDs from Products > Attribute Values, for example 3,4

AC. price - mandatory. Numbers only, no currency symbol. A variant counts as filled in when
      this column has a value, so this is the column that decides how many variants a row has.

AD. special_price - optional. The discounted price. It must be lower than the price.

AE. sku_variant - optional. Your own code for this variant.

AF. stock_variant - optional. Stock for this variant. Use this instead of the product stock
      column when each variant has its own stock.
